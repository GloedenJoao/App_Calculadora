# Agent Instructions

## Project Overview
- This repository contains a simple Android calculator app.
- The app supports standard arithmetic operations, parentheses for order of operations,
  and an `Ans` token to reuse the last computed result.

## Development Notes
- Primary code lives in `app/src/main/java/com/example/calculadora`.
- UI layout lives in `app/src/main/res/layout/activity_main.xml`.
- Use Kotlin for app logic and keep formatting consistent with the existing codebase.

## Build & Run
- Open the project in Android Studio.
- Build with the Android Gradle plugin using the `app` module.
